# Send emails

Send transactional emails programmatically using KibaMail's API. This guide covers basic email sending, attachments, scheduling, tagging, and custom headers.

## 1. Basic Email Sending

Send a simple email with required fields. You'll need your API token and the recipient's email address.

### Required Parameters

- `from` - Sender email address (must be verified in your KibaMail account)
- `to` - Recipient email address
- `subject` - Email subject line
- `html` or `text` - Email content (at least one is required)
